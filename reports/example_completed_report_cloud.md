# Example Completed Report (Lab): Cloud Key Abuse

## Incident Details
- Incident ID: LAB-2026-002
- Category: Cloud Incident
- Severity: SEV-2
- Status: Resolved (Lab)

## Summary
Unusual API activity was observed from an unknown source using a service key. Key rotation and policy review were completed.

## Key Actions
- Compromised key disabled and rotated.
- Suspicious sessions revoked.
- IAM policies reviewed for excessive privilege.
- Audit logs analyzed for impacted resources.

## Outcome
No evidence of destructive actions. Guardrail recommendations were captured in post-incident review notes.
