# Example Completed Report (Lab): Storage Policy Data Exposure

## Incident Details
- Incident ID: LAB-2026-004
- Category: Data Exposure
- Severity: SEV-2
- Status: Resolved (Lab)

## Summary
A storage access policy misconfiguration exposed internal documents to unintended access. Access was revoked and logging was reviewed.

## Key Actions
- Public/external access disabled.
- Access keys rotated for affected service identities.
- Access logs reviewed for exposure-window activity.
- Baseline policy guardrails documented for similar resources.

## Outcome
No confirmed regulated-data disclosure in this lab scenario. Preventive policy checks were added to follow-up actions.
