# Example Completed Report (Lab): Phishing Credential Harvest

## Incident Details
- Incident ID: LAB-2026-001
- Category: Phishing / Account Compromise
- Severity: SEV-2
- Status: Resolved (Lab)

## Summary
A phishing email impersonating finance was delivered to multiple recipients. One user submitted credentials. Sessions were revoked and password reset immediately.

## Key Actions
- Message quarantined tenant-wide.
- Sender/domain blocked.
- User credentials reset and sessions revoked.
- Mailbox rules reviewed; no malicious persistence found.

## Outcome
No confirmed lateral movement. Additional anti-phishing controls and awareness guidance were documented for follow-up.
