# Scenario: Phishing Credential Harvest Attempt

## Scenario Summary
A user reports a suspicious invoice email. Message includes a link to a fake login page. One user clicked and submitted credentials before reporting.

## Objectives
- Practice phishing triage and mailbox-wide containment.
- Validate account compromise follow-on actions.
