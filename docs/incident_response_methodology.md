# Incident Response Methodology (Portfolio Lab)

This lab follows a structured lifecycle inspired by NIST-style phases:

1. Preparation
2. Identification
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

## Severity and Escalation
- Severity is assigned using impact + scope + confidence.
- Escalation occurs when business-critical systems, privileged identities, regulated data, or multi-system compromise is suspected.

## Documentation Expectations
- Every incident starts with an intake form.
- Analysts maintain a UTC timeline of key decisions/actions.
- Evidence collection is documented with source and timestamp.
- Stakeholder updates are concise, objective, and periodic.

## Portfolio Lab Boundaries
- Scenarios are sanitized and educational.
- No production customer data is stored.
- No claims of enterprise command authority are implied.
