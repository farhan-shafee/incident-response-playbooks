# Evidence Collection Checklist (Template)

## Chain-of-Custody Basics
- [ ] Evidence ID assigned
- [ ] Collector documented
- [ ] Collection timestamp (UTC)
- [ ] Source system and method recorded
- [ ] Integrity method recorded (hash/signature where possible)

## Typical Evidence Sources
- [ ] Endpoint telemetry (alerts/process tree)
- [ ] Authentication and identity logs
- [ ] Email artifacts (headers, message IDs)
- [ ] Network/DNS/proxy logs
- [ ] Cloud audit/configuration logs
- [ ] Ticket/chat records relevant to incident timeline

## Handling
- [ ] Stored in approved location
- [ ] Access limited to authorized responders
- [ ] Retention requirement noted
